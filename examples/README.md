# Moment Notes Examples

Examples are for low-frequency quality calibration only. They help future agents understand what "good" and "bad" mean for Moment Notes, but they must not become templates to copy.

## Good Example Notes

A good public example should describe:

- the original photo scene type
- the intended emotional line
- why the subject priority is correct
- what the handwritten notes add emotionally
- how readability is protected
- why the original photo is clearly preserved

See `positive-cases.md` for approved positive example descriptions.

## Bad Example Notes

A bad-case report should describe:

- what failed
- whether the original photo changed
- which object should not have been emphasized
- whether annotation density, readability, wording repetition, or gear naming caused the issue
- how the next generation should be corrected

## Public-Safety Rule

Do not add raw user photos, private screenshots, bad-case screenshots, or local test images here unless they have been explicitly reviewed and approved as public-safe.

Use `assets/examples/` only for confirmed public-safe images. Examples may guide style density and QA judgment, but the model must not copy their exact composition, objects, annotations, or wording.
