# Public Example Assets

This directory is reserved for public-safe Moment Notes example images.

Do not place private photos, raw test images, unreviewed outputs, or bad-case screenshots here.

When a public example is approved, keep pairs or sets easy to inspect:

```text
01-scene-name-original.png
01-scene-name-annotated.png
```

Examples are calibration assets only. They must not be copied as fixed layouts, object choices, handwritten notes, or doodle patterns.
